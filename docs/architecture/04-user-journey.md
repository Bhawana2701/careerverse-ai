# User Journey

## New User

1. User visits CareerVerse AI.
2. Creates an account or signs in with Google.
3. Completes profile information.
4. Chooses career goal or takes AI Career Assessment.
5. AI generates a personalized roadmap.
6. User starts learning.
7. Progress is tracked.
8. AI Mentor provides guidance.
9. User practices interviews.
10. User applies for internships/jobs.

---

## Returning User

1. Login
2. Dashboard
3. Continue roadmap
4. Complete tasks
5. AI Mentor check-in
6. Weekly progress review
7. Interview practice
8. Resume improvement
9. Career readiness score updates

---

## AI Mentor Journey (Future)

1. User schedules mentoring session.
2. AI reviews user progress.
3. AI discusses strengths and weaknesses.
4. AI updates roadmap.
5. AI assigns next week's goals.
6. AI sends follow-up reminders.

---

## AI Interview Journey (Future)

1. Select company (Amazon, Google, etc.).
2. Select interview type.
3. AI starts interview.
4. User answers by voice or video.
5. AI asks follow-up questions.
6. AI evaluates responses.
7. Detailed feedback report is generated.

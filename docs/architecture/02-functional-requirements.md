# Functional Requirements

## Overview

CareerVerse AI is an AI-powered Career Intelligence Platform designed to guide learners from career discovery to job readiness through personalized AI assistance.

---

# User Management

## Authentication

- User Registration
- Login
- Logout
- Forgot Password
- Google Login
- Email Verification
- Profile Management

---

# Career Discovery

Users should be able to

- Search Careers
- Browse Career Categories
- Compare Careers
- View Career Details
- Save Careers
- Change Career Anytime

---

# AI Career Assessment

Users can

- Take Personality Assessment
- Take Interest Assessment
- Take Skill Assessment
- Skip Assessment
- Receive AI Career Recommendations

---

# Career Workspace

Every selected career creates a personalized workspace containing

- Overview
- Career Roadmap
- Skill Tracker
- Learning Resources
- Projects
- Certifications
- Resume
- Interview Preparation
- Progress Dashboard

---

# Personalized Roadmap

Roadmaps should adapt according to

- Education
- Current Skills
- Career Goal
- Learning Speed
- Available Time
- Budget

Each roadmap step contains

- Title
- Description
- Estimated Duration
- Difficulty
- Learning Resources
- Practice Tasks
- Projects
- Completion Status
